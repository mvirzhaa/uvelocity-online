# Gambar loading UVelocity

`uvelocity_loading.jpg` adalah ilustrasi yang dibuat khusus untuk halaman persiapan balapan UVelocity. Ukuran 1672 × 941 piksel; format JPEG memenuhi validator server. Sisi kiri disisakan untuk teks dan daftar kesiapan. Tidak ada progress atau jumlah pemain yang dibakar ke dalam gambar.

Cara memasang:

1. Masuk dengan akun admin dan buka **Admin → Musik & loading**.
2. Pilih `uvelocity_loading.jpg` pada **Tambahkan gambar JPEG**.
3. Tekan **Unggah JPEG** dan tunggu sampai server menyatakan berhasil.
4. Pilih gambar tersebut pada **Gambar halaman loading**.
5. Isi alasan perubahan dan tekan **Simpan pengaturan media**.
6. Coba persiapan pertandingan berikutnya. Gambar muncul di belakang informasi kesiapan arena.

Gambar ini tidak diaktifkan otomatis saat migrasi. Admin dapat mengganti atau menonaktifkannya. Gambar merupakan artwork, bukan screenshot mesin grafis game. Sumber dan prompt ada pada `docs/BRANDING.md`.
